## 2026-06-24 - Fix XSS Vulnerability via MIME Sniffing in Response.send() Fast Path
**Vulnerability:** A cross-site scripting (XSS) vulnerability existed where the `Response.send()` fast path (used for simple 200 OK responses with no headers) bypassed the addition of default `Content-Type` headers. This allowed browsers to MIME-sniff the returned raw data, leading to the execution of malicious HTML/JS payloads if user input was reflected.
**Learning:** Security mechanisms added below a performance fast-path exit (e.g., early returns like `end_fast`) must also be explicitly enforced within or prior to that fast path. Performance optimizations cannot skip security-critical headers.
**Prevention:** Ensure that `Content-Type` headers are always applied, even in optimized response branches. In `xyra/response.py`, the fast path was updated to add `Content-Type` headers (`text/plain` for strings, `application/octet-stream` for bytes) before falling through to standard output.
